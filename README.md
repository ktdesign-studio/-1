# Ксения Теселкина — портфолио AI Product Manager

Одностраничный сайт-портфолио: `index.html` + `assets/`.
Без сборки и зависимостей — открывается как есть, хостится на чём угодно
(GitHub Pages, Vercel, Netlify, любой статический хостинг).

## Структура

- `index.html` — главная страница (разметка, секции, слоты под фото)
- `resume.html` — резюме под вакансию AI Product Manager; кнопка
  «Скачать PDF» открывает печать с отдельными print-стилями
- `assets/css/style.css` — стили, анимации, адаптив, print-версия резюме
- `assets/js/main.js` — переключение языка RU/EN, моушен-эффекты
- `assets/img/` — сюда положить фото: `hero.jpg`, `about.jpg`, `avatar.jpg`, `og.jpg`
- `assets/img/certs/` — сканы сертификатов; после добавления файлов
  опишите их в массиве `window.CERTS` внизу `resume.html`
- `PROMPTS_HIGGSFIELD.md` — готовые промпты для генерации фото

## Что внутри

- **Два языка.** Переключатель RU/EN в шапке, выбор запоминается
  (localStorage). Все тексты — в словаре `I18N` в `assets/js/main.js`.
- **Моушен.** Интро-прелоадер, пословное появление заголовков, счётчики,
  параллакс, магнитные кнопки, наклон карточек, бегущие строки, кастомный
  курсор. Всё на ванильном JS, уважает `prefers-reduced-motion`.
- **Типографика.** Unbounded + Golos Text (Google Fonts) — оба отлично
  поддерживают кириллицу.
- **Адаптив.** Мобильное меню, перестройка сеток, проверено на 390px и 1440px.

## Как редактировать тексты

Русский и английский тексты лежат рядом в `assets/js/main.js` (объект `I18N`).
Русский текст также продублирован в разметке `index.html` — при изменении
формулировок обновите оба места (разметка нужна для корректного отображения
до загрузки JS и для поисковиков).

## Что осталось сделать вручную

1. Сгенерировать 4 фото по промптам из `PROMPTS_HIGGSFIELD.md` и положить
   в `assets/img/`.
