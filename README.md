# FitLife - Приложение для здорового питания

## Описание проекта
Приложение для людей, желающих сбросить вес и научиться питаться правильно. Основная целевая аудитория - женщины в возрасте 18-50 лет.

## Структура проекта

### Основные страницы:
- `index.html` - Главная страница приложения
- `profile.html` - Профиль пользователя
- `dashboard.html` - Панель управления
- `food-diary.html` - Дневник питания
- `calorie-calculator.html` - Калькулятор калорий
- `recipes.html` - Рецепты
- `shopping-list.html` - Список покупок
- `games.html` - Игры и обучение
- `calorie-game.html` - Игра "Запомни калорийность продукта"
- `progress.html` - Прогресс пользователя
- `settings.html` - Настройки

### Навигационная структура:
```
index.html (главная)
├── profile.html
├── dashboard.html
├── food-diary.html
│   ├── calorie-calculator.html
│   └── recipes.html
│       └── shopping-list.html
├── games.html
│   └── calorie-game.html
├── progress.html
└── settings.html
```

## Особенности реализации

### Игра "Запомни калорийность продукта"
- Полностью функциональная игра с JavaScript
- 8 различных продуктов для изучения
- Система обратной связи (правильно/неправильно)
- Подсчет статистики и точности ответов
- Возможность повторной игры

### UX-принципы
- Четкая навигация между страницами
- Логическая группировка функций
- Обратная связь для пользователя
- Прогрессивное раскрытие информации
- Консистентность интерфейса

## Технические детали
- Чистый HTML без CSS для фокуса на структуре
- JavaScript для интерактивности игры
- Семантическая разметка
- Адаптивный дизайн (viewport meta tag)
- Доступность (alt-атрибуты, семантические теги)
